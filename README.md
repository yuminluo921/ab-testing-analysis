# A/B 测试与统计学假设检验 (A/B Testing & Hypothesis Testing)

## 📖 项目背景
在互联网电商场景中，产品经理希望验证将商品页面的“购买”按钮由灰色（对照组 A）改为红色（实验组 B）是否能够显著提升用户的转化率。本项目通过统计学假设检验和业务指标计算，评估实验效果，并给出是否全量上线的业务建议。

## 🛠️ 技术栈
- **编程语言**：Python 3
- **数据生成与处理**：Numpy, Pandas
- **统计检验**：Scipy, Statsmodels
- **数据可视化**：Matplotlib, Seaborn

## 🔍 核心分析流程与结论

### 1. 实验设计与数据模拟
- 随机将 10,000 名用户分流为实验组 B 和对照组 A（各 5000 人）。
- 对照组实际转化率：**9.58%**。
- 实验组实际转化率：**11.34%**。

### 2. 统计学假设检验 (双样本比例 Z 检验)
- **原假设 (H0)**：两组转化率无显著差异。
- **计算得出 P-value = 0.0020**。因为 P < 0.05，拒绝原假设，证明红色按钮的提升具有高度统计学显著性。

### 3. 业务收益评估 (Lift & 置信区间)
- **相对提升率 (Lift)**：**18.37%**。
- **绝对提升量 95% CI**：[0.56%, 2.96%]。
- **相对提升率 95% CI**：[5.85%, 30.89%]。
- **业务决策**：因为置信区间下限远大于 0，说明收益极其稳定，建议立即全量上线。
